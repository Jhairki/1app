The one being copied from — usually the live site.

One per line. There is no navigation discovery here: the two sites can have different menus, so you say which pages are equivalent.
Only needed when the platforms build URLs differently — a live site in /section/ and a CMS in /section.htm, for example. Paired by line with the source paths, so leave blank lines out and keep the same order and count. Leave empty to use the same paths on both sides.
For when the source site blocks automated requests (an anti-bot challenge, for example). Leave this empty to fetch the source pages normally. Otherwise, browse each source page yourself and save its HTML with the QA Page Exporter extension into this folder — a path on the machine running this app.

CheckWhat it catches
